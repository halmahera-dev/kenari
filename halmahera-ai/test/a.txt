HalmaheraAI digunakan untuk memudahkan pengguna untuk mencari beasiswa melalui pendekatan berbasis agentic ai, kami menggunakan ibm watsonx orchestrate sebagai platform utama untuk mengembangkan sistem ini. Dengan memanfaatkan kemampuan natural language processing (NLP) dari ibm watsonx orchestrate, HalmaheraAI dapat memahami kebutuhan pengguna secara lebih mendalam dan memberikan rekomendasi beasiswa yang sesuai dengan profil mereka.

Agent yang kami gunakan adalah agent berbasis aturan yang dirancang untuk menilai kriteria beasiswa berdasarkan input pengguna. Agent ini mampu mengumpulkan informasi seperti latar belakang pendidikan, bidang studi, prestasi akademik, dan kebutuhan finansial pengguna. Berdasarkan data tersebut, agent akan mencocokkan profil pengguna dengan database beasiswa yang tersedia dan memberikan rekomendasi yang paling relevan. Agent ini dinamakan Halmahera Agent.

Terdapat juga Agent guardrails, yang digunakan untuk memberikan validasi terkait input pengguna dan memastikan bahwa informasi yang diberikan sesuai dengan standar yang telah ditetapkan. Agent guardrails ini berfungsi untuk meminimalisir kesalahan dalam proses pencarian beasiswa dan memastikan bahwa rekomendasi yang diberikan benar-benar sesuai dengan kebutuhan pengguna.

Pada Halmahera Agent, terdapat 3 tools, ada create application, create task, dan search scholarship. search scholarship digunakan untuk mencari beasiswa berdasarkan kriteria yang telah diinputkan oleh pengguna. create application digunakan untuk membuat aplikasi beasiswa berdasarkan beasiswa yang telah ditemukan, dan create task digunakan untuk membuat daftar tugas yang harus diselesaikan oleh pengguna dalam proses pengajuan beasiswa berbentuk roadmap. Tools ini dapat digunakan secara paralel untuk memberikan pengalaman yang lebih efisien bagi pengguna.

Kami juga menggunakan ibm/granite-embedding-107m-multilingual sebagai model embedding untuk memproses dan memahami teks dalam berbagai bahasa. Model ini memungkinkan HalmaheraAI untuk menangani input dari pengguna yang berasal dari latar belakang bahasa yang berbeda, sehingga memperluas jangkauan layanan kami. Kami menggunakan elastic search sebagai database berbasis pencarian dengan metode pencarian hybrid (keyword dan embedding) untuk menyimpan dan mengelola data beasiswa. Dengan menggunakan elastic search, HalmaheraAI dapat melakukan pencarian beasiswa dengan cepat dan akurat berdasarkan kriteria yang telah ditentukan oleh pengguna.
